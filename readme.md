# Student Expense Tracker

A dynamic web application built using Python Flask to record and track student expenses.

## Features

- Add expenses with description, category, and amount
- Validate expense input
- Display recorded expenses
- Calculate total expenses
- JSON API for expense data
- Health check endpoint
- Automated tests using pytest
- Code quality checks using flake8

## Technologies

- Python
- Flask
- HTML/CSS
- pytest
- flake8
- Git & GitHub
- GitHub Actions
- Render
- Docker
